# Quickdraw Achievement

How to earn the Quickdraw badge:

1. **Create a test repository** — Click the "+" in the top-right corner of your GitHub homepage, select "New repository", name it anything (e.g. `test-quickdraw`), set it to **Public**, check "Add a README file", then click Create.
2. **Open an issue** — Go to the new repository, click the **New issue** button on the Issues tab, write any title (e.g. "test"), then click **Submit new issue**.
3. **Close it immediately** — After the issue is created, a **Close issue** button appears at the bottom right. Click it **right away**. The issue must be closed within **5 minutes** of creation.
4. **Check your achievement** — Refresh your GitHub profile. The Quickdraw badge (👋) should appear in the Achievements section.

**Notes:**
- Badges are not shown instantly — it may take a few minutes, so refresh again later.
- If the badge still doesn't appear, open the Achievements section on your profile and check whether it was accidentally set to hidden. Click Hide/Unhide to toggle it back.
